# TEDUH 2.0
**Temukan Ketenangan, Kenali Dirimu.**

![TEDUH App Icon](app/src/main/res/drawable/foto_teduh.png)

TEDUH 2.0 adalah aplikasi berbasis Android (Kotlin & Jetpack Compose) yang dirancang sebagai jurnal kesehatan mental harian. Aplikasi ini menyediakan ruang aman, personal, dan mudah digunakan untuk mengenali perasaan, memahami kondisi diri, serta menjaga kesehatan mental secara mandiri.

---

## 🌟 Fitur Utama
1. **Mood Tracker (Pencatatan Mood):** Catat perasaan harianmu beserta skor dan pemicunya untuk memahami pola emosimu.
2. **Tes DASS-21 (Asesmen Mandiri):** Tes psikologis ringan untuk mengukur dan memantau tingkat Depresi, Kecemasan (Anxiety), dan Stres.
3. **Analisis Mood:** Pantau perkembangan kondisimu dan lihat rekapitulasi *mood* mingguanmu.
4. **Rekomendasi Aktivitas:** Dapatkan saran aktivitas interaktif (seperti meditasi, latihan pernapasan, dll) yang disesuaikan dengan suasana hati dan tingkat stres terakhirmu.
5. **Ruang Bersama (Community Screen):** Wadah interaktif untuk membagikan pengalaman dan dukungan kepada sesama pengguna TEDUH.

---

## 🛠️ Teknologi yang Digunakan
- **Bahasa Pemrograman:** Kotlin
- **UI Framework:** Jetpack Compose (Modern Declarative UI) & Material Design 3
- **Local Database:** SQLite (Menggunakan `SQLiteOpenHelper`)
- **Keamanan:** Password Hashing sederhana (PBKDF2) untuk mengamankan data pengguna di *local storage*.

---

## 🚀 Cara Menjalankan Proyek (Bagi Developer)
1. *Clone* repositori ini:
   ```bash
   git clone https://github.com/Er1c911/TEDUH.git
   ```
2. Buka proyek ini menggunakan **Android Studio** (Disarankan versi terbaru yang mendukung penuh Jetpack Compose).
3. Tunggu hingga proses *Gradle Sync* selesai.
4. Jalankan aplikasi dengan menekan tombol **Run (Shift + F10)** menggunakan Emulator Android atau *Device* Fisik.
